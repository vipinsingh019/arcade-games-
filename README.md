# 🎮 ArcadeVerse

**ArcadeVerse** is a responsive browser-game portal containing six original mini-games. Browse the game cards, search by name, filter by category, and launch a game directly in your browser.

🌐 **Live demo:** https://arcadegame29.netlify.app

## 🕹️ Games included

| Game | Category | How to play |
|---|---|---|
| Snake Rush | Classic | Eat fruit and avoid walls and your own tail. |
| Neon Lane Racer | Racing | Dodge traffic and travel as far as possible. |
| Brick Buster | Arcade | Bounce the ball and break the bricks. |
| Memory Match | Puzzle | Find all matching pairs of cards. |
| 2048 Merge | Puzzle | Combine matching number tiles. |
| Cosmic Clicker | Arcade | Tap the energy core before the timer ends. |

## ✨ Features

- Responsive layout for desktop and mobile screens
- Search games by name or description
- Category filters
- Random game button
- Six playable mini-games
- No account or backend required
- Runs locally in a modern browser

## 🚀 Run locally

1. Download or clone this repository.
2. Keep `index.html`, `style.css`, and `games.js` in the same folder.
3. Open `index.html` in a modern browser.

```bash
git clone https://github.com/YOUR-USERNAME/ArcadeVerse.git
cd ArcadeVerse
