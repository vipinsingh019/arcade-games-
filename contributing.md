# Contributing to ArcadeVerse

Thanks for your interest in improving ArcadeVerse!

## How to contribute

1. Fork the repository.
2. Create a branch for your change.
3. Make a focused improvement.
4. Test the website in a modern browser, including a mobile-sized viewport.
5. Open a pull request explaining what changed.

## Contribution ideas

- Add another original mini-game.
- Improve touch controls and accessibility.
- Improve mobile layout or performance.
- Fix bugs and update documentation.

Please do not add copyrighted game assets or branding unless you have permission to use them.
